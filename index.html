Gestor de Tareas

Organiza tu día, controla tu productividad

Aplicación interactiva para gestionar tus tareas diarias. Asigna categorías, define prioridades, establece fechas límite y lleva un registro del tiempo estimado. Todos los datos se guardan automáticamente en tu navegador mediante localStorage, y al iniciar se cargan tareas base desde un JSON externo.

Cómo usar

1
Crea una tarea

Escribe un título, selecciona categoría, prioridad, fecha de vencimiento y tiempo estimado en minutos.

2
Filtra y organiza

Usa los filtros para ver todas las tareas, solo las pendientes o solo las completadas.

3
Edita o elimina

Cada tarea tiene botones para editarla o borrarla. También puedes marcarla como hecha con el checkbox.

4
Guardado automático

Tus datos persisten en el navegador. Cerrá la pestaña y al volver todo sigue igual.
